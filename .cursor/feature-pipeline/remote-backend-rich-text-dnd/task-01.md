# Task 01: Prove PGlite and the Postgres driver on Node 26

## Context
The AI Work Board (repo root `/Users/neazmahmood/Desktop/projects/practice/ai-work-board`, Node 26, pnpm, TypeScript run directly by Node's type stripping, Vitest) is moving its storage from SQLite (`better-sqlite3`) to Postgres when hosted and PGlite (embedded Postgres) when run locally. Before any code is converted, this task proves that both libraries load and work on this project's Node 26 engine, under both plain `node` and Vitest's node environment. If they don't, the whole plan stops, so report clearly.

## Do
- Add runtime dependencies with `pnpm add @electric-sql/pglite postgres` (latest stable versions).
- Create `test/pglite-proof.test.ts` with these cases:
  - **In-memory PGlite** (`new PGlite()`): create a table with `id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, name TEXT NOT NULL`; insert a row with `RETURNING id` and assert the id is a JS `number`; run a transaction (`db.transaction(async (tx) => …)`) that inserts and then throws, and assert the row was rolled back; run `SELECT COUNT(*)::int AS n` and assert `n` is a number.
  - **Directory PGlite** (`new PGlite(<tmp dir>)`, tmp dir from `fs.mkdtempSync(path.join(os.tmpdir(), "awb-pglite-"))`): create a table, insert, `close()`, reopen the same directory, and assert the row persisted. Remove the tmp dir afterwards.
  - **Postgres driver**: `import postgres from "postgres"`. Construct a client `postgres("postgres://u:p@127.0.0.1:1/db", { max: 1 })` without querying, and `await sql.end()`. This proves the module loads.
  - **Optional real Postgres**: if `process.env.TEST_DATABASE_URL` is set, run `select 1 as x` through the `postgres` driver and assert `x === 1`. Otherwise skip this case with `test.skipIf`.

## Follow these existing patterns
- `test/skeleton.test.ts`: Vitest structure (`describe`/`test`, `beforeAll`/`afterAll`, temp dirs).
- `vitest.config.ts`: tests live under `test/**/*.test.ts` in the node environment.

## Do not
- Touch files outside: `package.json`, `pnpm-lock.yaml`, `test/pglite-proof.test.ts`
- Change any production code under `src/`
- Add dependencies other than `@electric-sql/pglite` and `postgres`, reformat unrelated code, or commit

## Done when
- The new test file passes, and the existing suite still passes.
- `node --input-type=module -e "import { PGlite } from '@electric-sql/pglite'; const db = new PGlite(); const r = await db.query('select 1 as x'); console.log(r.rows[0].x); await db.close();"` prints `1` from the repo root.
- `pnpm test` passes
- `pnpm typecheck` passes
